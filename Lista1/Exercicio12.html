O HTTP é um protocolo usado para fazer a comunicação entre o navegador e os servidores de internet
Quando acessamos um site o navegador envia uma requisição ao servidor, e o servidor responde com uma resposta.

Detalhes de um campo de Request :


  • :method: Indica qual método foi utilizado na requisição, no caso da imagem abaixo tirada do google docs é GET
  • :authority: Indica qual servidor a requisição está sendo enviada
  • :path: Indica o caminho do recurso que esta sendo solicitado no servidor
  • :schema: Indica o protocolo utilizado para comunicação, no caso abaixo é o HTTP
  • Accept: Informa quais tipos de conteudos o navegador aceita receber do servidor
  • Accept - Language: Indica os idiomas preferidos pelo navegador

Detalhes de um campo de Reponse


  • Alt-Svc: Informa que o servidor oferece outros protocolos/serviços para conexão
  • Cache-Control: Define como o conteudo deve ser armazenado no Cache
  • Content-Encoding: Indica como o conteudo foi compactado, nesse caso foi por gzip
  • Conten-Security-Policy: Define regras de segurança para controlar o que é seguro carregar na pagina
